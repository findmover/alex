【本地运行】（需要 Node 18 以上）
  git clone -b claude/determined-gauss-ften0r https://github.com/findmover/alex.git && cd alex/video
  npm install
  npm run dev                                                     # 打开 Remotion Studio 预览、逐帧调整
  npx remotion render AlexWebb out/wait-for-light.mp4 --crf=18    # 渲染成片，约 15 分钟
  npx remotion still Cover-Portrait out/cover.png                 # 导出封面（横版用 Cover-Landscape）
  改了文案后先运行 npm run fonts 重新生成字体子集；换了原作图片后运行 python3 scripts/prepare-photos.py（需要 Pillow）。
  本地渲染会自动下载 Chrome，不需要加 --browser-executable 参数，那是云端环境才用的。
