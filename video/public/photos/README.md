# 作品图片放这里

用 git 提交到分支 `claude/determined-gauss-ften0r` 即可，我会拉取使用。

当前已收录 35 张用户提供的图片，按“编号-作者-地点-年份-画面描述”命名，保留原扩展名和图片内容。完整文件索引、原名对应、作者、年份、来源及待核实条目见 [图片命名与来源](../../../docs/03-图片命名与来源.md)。其中旅鸽标本照片作者为 Rebecca Norris Webb；3 张未确认归属的图片以 `unverified` 标记。

建议命名（对应脚本里的图位，可以一张图用在多个图位）：

| 文件名 | 用在哪一幕 | 最好选什么样的照片 |
|---|---|---|
| `01-reveal.jpg` | 开场「剩下的 1%」揭晓 | 你最喜欢、最有冲击力的一张 |
| `02-stories.jpg` | 「一张照片里好几个故事」 | 人物多、各做各事的一张 |
| `03-light.jpg` | 关键词·热光 | 强烈阳光、饱和墙面、大块黑影 |
| `04-layers.jpg` | 关键词·层次 | 前中后景都有人 |
| `05-grid.jpg` | 关键词·分割 | 门框/墙/柱子把画面切成格子 |
| `06-edges.jpg` | 关键词·边缘 | 画面边上有被切掉一半的人 |

上表为视频图位的建议用途；本次实际文件名使用逐张来源命名，不另行复制成图位别名。

本次格式为 JPEG / WebP，保持用户原文件尺寸。作品名、年份和署名以来源文档的逐张记录为准；片中使用时应标注对应作者，待核实图片应先补全归属。
