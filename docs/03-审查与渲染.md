# 第三步：审查与渲染

## 看预览

- 关键帧截图：`docs/review/预览-*.jpg`
- 本地实时预览（可拖时间轴、逐帧看）：
  ```bash
  cd video
  npm install
  npm run dev        # 打开 Remotion Studio，选 AlexWebb 或 Scenes 里的单幕
  ```

## 改哪里

| 想改的 | 文件 |
|---|---|
| 屏幕文字、每幕时长 | `video/src/data/script.ts`（`[[ ]]` 包住的字会高亮） |
| 放原作图片 | 图片放 `video/public/photos/`，在 `video/src/data/photos.ts` 填路径和作品名 |
| 插画（街角、人物、颜色） | `video/src/components/Street.tsx` |
| 单幕动画 | `video/src/scenes/*.tsx` |

改了文案后运行 `npm run fonts`，重新生成字体子集（否则新字会显示成后备字体）。

## 审查清单

- [ ] 前 3 秒：第 0 帧就有“99% 都是失败”大字
- [ ] 文字停留时间够读完（每屏 ≤ 14 字，≥ 2 秒）
- [ ] 黑白 → 彩色的转折足够有冲击力
- [ ] 原作：不调色、不裁关键部分、每张完整停留 2~3 秒、标注作品名和版权
- [ ] 事实：年份、书名、引语与 `01-资源收集.md` 一致
- [ ] 抖音横屏在手机竖着看时字是否够大

## 你确认后渲染

```bash
cd video
npx remotion render AlexWebb out/alex-webb.mp4 --crf=18
```
（约 80 秒，1920×1080，30fps。）
