# 第二步：脚本（抖音版 v1）· 待审查

## 基本设定

| 项目 | 设定 |
|---|---|
| 平台 | 抖音 |
| 画幅 | 竖屏 9:16，1080 × 1920 |
| 时长 | 约 78 秒 |
| 配音 | 无。全部信息靠**屏幕大字**，配背景音乐 |
| 引入点 | 韦伯的原话：“这种摄影 99% 都是失败。” |
| 画面 | 你上传的原作 + 原创示意动画（讲构图原理） |

**无配音的写法原则**
- 每屏只放一句话，最多 14 个字左右，停留 2~4 秒（按每秒约 5 个字的阅读速度）。
- 重点词用黄色高亮。
- 前 3 秒必须抛出钩子，不能先介绍人物。
- 文字放在画面中部偏上。抖音底部约 25% 会被标题、按钮挡住，那里不放任何内容。

## 需要你决定 / 提供

1. **原作图片**：按 `video/public/photos/README.md` 的命名上传，最少 1 张（可以一张图多处复用），理想是 6 张。
2. **背景音乐**：你来选（抖音剪辑时加也行），还是我在视频里先留音轨位置？
3. **片尾引导语**：要不要加“关注我，下期讲 ×××”？下期讲谁？
4. **时长**：78 秒可以吗？想更短的话，可以把关键词压成 3 个（去掉“分割”），约 60 秒。
5. **文案语气**：现在偏克制、偏“美术课”。想更口语、更网感也可以改。

> 你确认这一版后，我再把 Remotion 代码改成竖屏无配音版本，渲染几张关键帧截图给你看，最后由你决定是否渲染成片。
