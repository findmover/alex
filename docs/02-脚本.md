# 第二步：脚本（抖音版 v3 · 99% 开场 + 故事）· 待审查

## 基本设定

| 项目 | 设定 |
|---|---|
| 平台 | 抖音，**横屏 16:9（1920 × 1080）** |
| 时长 | **约 80 秒** |
| 配音 | 无。全部信息靠屏幕大字，配背景音乐 |
| 开场钩子 | 他的原话：**“这种摄影，99% 都是失败。”**（前 3 秒） |
| 主线 | 一个故事：1975 年，二十出头的韦伯拍不下去了 → 去了海地 → 改拍彩色 |
| 结尾回扣 | 回到 99%：他一直走、一直等，等那 1% |

**写法原则**
- 每屏一句，尽量不超过 14 个字，停留 2~4 秒。
- 重点词用黄色高亮（下表中用 <mark>标记</mark>）。
- 故事部分画面是黑白，他“发现颜色”那一刻整个视频变成彩色。这是全片最重要的视觉转折。
- 画面：自绘示意插画 + 3D 动画讲原理（原创，不复制任何原作），原作图片到位后在每个关键词末尾完整展示。

**事实依据**（都来自已核实的资料，见 `01-资源收集.md`）：70 年代中期在美国南方拍黑白，照片不够打动人；1975 年读了格雷厄姆·格林写海地的小说《喜剧演员》后去了海地；约三年后意识到必须拍彩色。
“阳光像刀”这类说法是文案修辞，**不是他的原话**，画面上不加引号。

## 美术方向：让他的作品当主角

你的反馈：他的色彩特别鲜艳突出，作品要突出他的个人气息和艺术特色。据此调整：

1. **原作优先，示意插画退居二线**
   - 讲“热光 / 层次 / 边缘”时，**直接在他的原作上做标注**：描边、圈出人物、把前中后景分层高亮。不再用自绘的卡通示意图代替。
   - 示意插画只在故事段（黑白的美国南方、去海地）作过渡用。
2. **颜色从他的照片里取**
   - 全片的强调色（高亮字、标注线）从原作里取色，典型是橙红墙、钴蓝、明黄、翠绿，不另外发明配色。
   - 背景用接近他阴影的深黑，让照片的颜色“烧”出来。
3. **不改动原作**
   - 不调色、不加滤镜、不裁掉关键部分，只做推拉和标注。
   - 唯一例外是故事段刻意用的“黑白 → 彩色”转场，而且只在那一刻用。
4. **文字克制**
   - 字体用细一点的宋体，白字配少量取色高亮，不加花哨的底板和特效，不和照片抢戏。
5. **节奏跟着“看照片”走**
   - 每张原作至少完整停留 2~3 秒不加字，给观众自己看的时间。这正是韦伯照片需要的“慢看”。

## 分镜表

### 第一幕 · 钩子（0–8 秒）
| 时间 | 屏幕文字 | 画面 |
|---|---|---|
| 0–3s | **“这种摄影，<mark>99%</mark> 都是失败。”** | 彩色印样（contact sheet）铺满全屏，一格格变灰 |
| 3–5s | —— Alex Webb，<mark>玛格南</mark>摄影师 | 灰格继续暗下去，只剩一格亮着 |
| 5–8s | 可剩下的 1%，让他成了<mark>美国彩色摄影的先驱</mark> | 那一格放大，满屏原作 `01-reveal.jpg` 一闪而过 |

### 第二幕 · 困境（8–16 秒）｜黑白
| 时间 | 屏幕文字 | 画面 |
|---|---|---|
| 8–11s | 故事从 1975 年说起 | 画面褪成黑白 |
| 11–16s | 他在美国南方拍黑白照片，<br>自己都觉得<mark>不够打动人</mark> | 黑白示意插画：小镇、墙、路人 |

### 第三幕 · 转折（16–24 秒）｜黑白
| 时间 | 屏幕文字 | 画面 |
|---|---|---|
| 16–20s | 他读到一本写<mark>海地</mark>的小说，害怕又着迷 | 一本书的剪影翻开 |
| 20–24s | 于是，他去了海地 | 地图上从美国画一条线到海地 |

### 第四幕 · 发现颜色（24–34 秒）｜黑白 → 彩色
| 时间 | 屏幕文字 | 画面 |
|---|---|---|
| 24–28s | 那里的阳光很硬，<mark>颜色烫眼</mark> | 黑白插画，高光处开始渗出颜色 |
| 28–31s | 他终于明白：<mark>黑白装不下这些</mark> | **全画面一下变成彩色**（全片视觉转折点） |
| 31–34s | 从此，他只拍彩色 | 原作 `01-reveal.jpg` 完整出现，缓慢推近 |

### 第五幕 · 他的彩色好在哪（34–58 秒，三个词，各 8 秒）
| 时间 | 屏幕文字 | 画面 |
|---|---|---|
| 34–42s | **① 热光**<br>饱和的颜色 + <mark>纯黑的影子</mark> | 示意图：柔光切成硬光，影子变黑块 → 原作 `03-light.jpg` |
| 42–50s | **② 层次**<br>前景、中景、背景，<mark>同时有事发生</mark> | 示意图拆成三层纸片在 3D 里分开 → 原作 `04-layers.jpg` |
