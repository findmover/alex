# 《等光》—— Alex Webb 艺术短片 · 创意方案 v5

> 从“讲解”改为“作品”：不再用“关键词①②③”“下次试试”这类教程语气。
> 知识藏进画面里，文字只留诗一样的短句。

---

## 1. 主题

**《等光》 WAITING FOR LIGHT**

- 韦伯说，这种摄影 99% 都是失败。他一直在走，一直在等，等光、等人、等一切在同一瞬间对上。
- 他的回顾集叫 *The Suffering of Light*（光的受难）。书名出自歌德《色彩论》：“颜色是光的作为与受难。”（⚠️ 原文待对照）
- 所以全片只讲一件事：**一个人，在混乱里等光。**

**一句话创作意图**：让观众在 80 秒里，从“99% 都是失败”的惊讶，走到“原来这 1% 是这样被等出来的”。

**情绪三词**：炽热 · 沉静 · 复调

---

## 2. 动效语言（motion-art-direction：Premium / 沉静-柔和）

| 项目 | 唯一选择 |
|---|---|
| 缓动 | 入场 `cubic-bezier(0.16, 1, 0.3, 1)`；镜头 `cubic-bezier(0.65, 0, 0.35, 1)`。全片只用这两条 |
| 基本时间单位 | 1 拍 = 25 帧（72 BPM，0.833 秒）。所有时长都是它的倍数 |
| 转场 | 硬切为主；一次匹配剪辑（亮着的一格 → 原作）。不用划像、旋转 |
| 文字 | 逐行遮罩升起 + 轻微模糊转清晰；行间隔 3 帧；位移 ≤ 24px；无回弹 |
| 镜头 | 每个镜头只做一种运动：推 / 拉 / 环绕 / 穿行，时长 2–4 秒 |
| 停顿 | 每句话落定后至少停 1 秒；每张原作至少完整停 2 秒不加字 |
| 唯一的“惊艳时刻” | 海地 1979：黑白 → 颜色从红墙里烧出来 |

**画面层级**：原作永远是主角；3D 空间、尘埃、光束是环境层，只做慢速漂移；文字是配角，放在三分线上，给照片让位。

**配色**：底色是接近他阴影的深黑 `#0b0a09`，纸色 `#efe9dd`；唯一强调色取自海地 1979 的红墙，并提亮以适配暗底：`#ee6a3a`。

**字体**：思源宋体 500，72px，字距 0.06em；英文用思源黑体 22px，字距 0.3em，全大写，像展签。

**章节字**：影 · 层 · 边，每个 360px，低透明度，贴在画面一角，像展览的章节墙。

| **等 · 99%** | 12 拍 / 10s | 回到序幕的灯箱（首尾呼应） | 镜头沿灯箱缓缓平移，底片一格格暗下去；红色油性笔圈出一格（手绘抖动的线条） |
| **廊 · 1%** | 10 拍 / 8.3s | 3D 画廊：每幅作品上方一束射灯，地面有淡淡倒影 | 镜头沿走廊穿行，18 幅作品两侧掠过。唯一的“快”段落 |
| **终 · 等光** | 8 拍 / 6.7s | 黑场，尘埃慢慢飘 | 标题“等光”逐字显现；英文展签；版权与出处 |

**全片环境层**：每一幕都有细胶片颗粒（每帧变化的噪点，约 4% 强度）、暗角，以及漂浮尘埃（有景深，近大、远小、远处更模糊）。
