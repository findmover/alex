# 封面设计理念：Chromatic Patience（色彩的耐心）

一块深黑，几乎是虚空，只在一处被光点燃。整幅画面的重量都压在“唯一的亮处”：一张照片，像暗房里刚刚显影的那一格。周围大面积留黑，不是空白，而是等待本身。构图的张力来自比例：九成的暗，承托一成的光。

颜色只有三种：影子的黑、纸的米白，和一种从照片里取来的红。红只出现一次，落在一个字上，像显影液里第一处泛起的颜色。它不装饰，只指认：光就在这里。所有其他元素都退后一步，把位置让给这一处炽热。

文字很少，并被当作建筑构件来用。一个巨大的宋体双字标题竖立或横陈，笔画的起落要像刀刻；一行极小、字距极宽的英文展签，像美术馆墙上的铭牌。它们与照片之间的距离经过反复测量，每一处间隔都属于同一个网格，每一道边都对齐到像素，这是长时间打磨的结果，不是随手摆放。

材质是胶片与相纸：细腻的颗粒，边缘极轻的暗角，照片四周一道克制的白边，像被人亲手裱在卡纸上。没有投影特效，没有渐变装饰，没有多余的线。完成度来自删减：每一次想加东西的冲动，都换成把已有的东西摆得更准。

这应当看起来像一位顶尖的书籍设计师，为一本摄影集花了数周时间调整的封面。安静、昂贵、笃定。
